

## Shared website standards

Read WEBSITE_BUILD_STANDARDS.md before website changes and apply relevant requirements.
Existing project instructions and explicit user instructions take precedence. Keep
project-specific exceptions in PROJECT_STANDARDS.md rather than editing the shared
file for one project's branding or technology. For restaurants, also read
RESTAURANT_WEBSITE_STANDARDS.md when present. Standards edits do not authorize
production database changes or website redesigns.
